# findr
findr. is a reel-first cinematic movie discovery platform designed around minimalism, immersive browsing, and fast decision-making.  

The experience replaces overwhelming catalog browsing with an elegant, gesture-driven interface focused entirely on discovering what to watch next through trailers, visuals, and fluid interaction.
